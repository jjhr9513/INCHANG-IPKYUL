# 인창고 3학년 입시결과 & 5등급제 환산

교사 내부 공유용 페이지입니다. `index.html` 한 파일에 모든 데이터가 들어 있습니다.

- 2024·2025학년도 고3 수시(4년제·전문대)·정시 합격 결과 (학생 이름·학번 제거, 익명 번호만 표시)
- 9등급 → 5등급 환산: 부산광역시교육청 누적비 기준 / 졸업생 변환 곡선(엑셀) 기준 전환 가능
- 5등급제 지원 가능 대학 라인(25대입 교과 70%컷·종합 50%컷)
- 2026학년도 고3 내신 분포(이름 없이 수치만)

## 깃허브 페이지로 올리기
1. 새 저장소를 만들고 `index.html`, `README.md`를 업로드
2. Settings → Pages → Branch: `main` / `(root)` → Save
3. 잠시 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 접속

## 내년에 갱신할 때
2026학년도 입시결과가 나오면 같은 양식의 엑셀을 주고 다시 생성하면 됩니다.
